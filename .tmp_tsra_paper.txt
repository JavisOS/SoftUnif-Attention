TSRA: Trace-Supervised Reasoning Attention for Multi-step Text Reasoning
Abstract
Multi-step reasoning over text requires models to
compose local facts into conclusions, a capability
often brittle in systematic generalization settings.
We proposeTSRA(Trace-Supervised Reasoning
Attention), a fully differentiable module that in-
stantiates a soft entity graph within a pretrained
encoder. TSRA introduces a query-guided step-
selection attention head trained with reasoning
traces (when available) to explicitly learn compo-
sitional inference paths. We further introduce a
bijective renaming regularization to enforce con-
sistency. Experiments on CLUTRR and Rule-
Taker demonstrate that TSRA significantly im-
proves length and depth generalization compared
to standard Transformer baselines.
1. Introduction
Multi-step reasoning over text often requires a model tocom-
posemultiple local facts into a final conclusion. While large
pretrained Transformers provide strong pattern recognition
(Vaswani et al., 2017; Devlin et al., 2019; Liu et al., 2019),
they can be brittle undersystematic generalizationsettings
where test instances require longer reasoning chains than
those seen during training. Two representative benchmarks
make this stress test explicit: CLUTRR measures relational
reasoning as a function of shortest-path hop length (Sinha
et al., 2019), and RuleTaker evaluates rule-based entailment
as a function of proof depth (Clark et al., 2020).
A common difficulty is that the intermediate reasoning tra-
jectory islatent: models are trained only with the final label,
yet are expected to repeatedly decidewhere to look next. In
entity-centric problems, this can be viewed as a sequence
of discrete “jumps” between entities (or mentions) to gather
evidence. If training data provides a reasoning trace (e.g., a
shortest path in synthetic relational graphs), it is natural to
use it to shape the model’s internal step-selection behavior—
but without requiring any trace at inference time.
We proposeTSRA(Trace-SupervisedReasoning
Attention), a simple training strategy that turns this intuition
into a fully differentiable module. TSRA instantiates an
internalsoft entity graphinside a pretrained encoder: text
is encoded into token representations; entity mentions are
aligned to token spans and pooled into entity vectors; and
an entity-attention layer produces a matrix ofstep-selection
logitsindicating, for each current entity, which entity should
be attended to next. Crucially, when traces are available,
TSRA applies cross-entropydirectly on these pre-softmax
attention logits, so the supervision acts on the step-selection
distribution itself rather than on an auxiliary classifier. At
test time, TSRA requirestext only.
We additionally adopt a lightweight invariance regularizer
tailored to compositional generalization. By applying a
bijection that renames entity surface forms (semantics pre-
served), we obtain an augmented view of the same instance
and penalize prediction drift between the two views, akin to
consistency regularization (Miyato et al., 2018; Xie et al.,
2020; Liang et al., 2021). This encourages the model to
rely on relational structure rather than memorizing entity
identities.
Contributions.This paper makes the following contribu-
tions: (i) we formalize TSRA as a trace-supervised step-
selection attention mechanism for entity-centric multi-step
reasoning; (ii) we show how to attach next-step (and op-
tional edge-relation) supervision directly to attention logits
while keeping inference text-only; (iii) we incorporate a sim-
ple bijective renaming augmentation with an explicit con-
sistency objective; and (iv) we evaluate under depth-based
systematic generalization protocols on CLUTRR (Sinha
et al., 2019) and RuleTaker (Clark et al., 2020).
2. Related Work
Multi-step reasoning and systematic generalization.
Multi-hop question answering and rule-based reasoning

decisions (Yang et al., 2018). CLUTRR and RuleTaker
further emphasizelength/depth generalization, where mod-
els must extrapolate to longer chains than observed during
training (Sinha et al., 2019; Clark et al., 2020).

3. Method
3.1. Problem Setting
Given a context/story s and a query q, our goal is to pre-
dict a label y∈ Y (e.g., a kinship relation in CLUTRR
(Sinha et al., 2019) or entailment in RuleTaker (Clark et al.,
2020)). We studysystematic generalizationby evaluating
performance as a function of reasoning depth (e.g., hop
length in CLUTRR or proof depth in RuleTaker). At infer-
ence time, the model takestext only. For synthetic datasets
that provide additional structure (e.g., a shortest reasoning
trace), we use such signalsonly during trainingto supervise
intermediate step decisions.
3.2. Overview
We instantiate asoft graphover discrete units extracted
from text (entities in our instantiation) inside a pretrained
encoder. The model consists of: (i) a Transformer text en-
coder producing token representations, (ii) a span alignment
module that pools token spans into unit vectors, and (iii)
aTrace-Supervised Reasoning Attention (TSRA)layer
that updates unit states and exposesstep-selection logits
for supervision when a reasoning trace is available. TSRA
combines two complementary computations:
• aglobal aggregationcomponent that composes evi-
dence across all units to enrich entity representations
with context, and
• astep-selectioncomponent that assigns a next-step
preference distribution (aspre-softmaxattention logits),
explicitly guided by the query target.
The final prediction combines a global classifier on the CLS
token and a pair classifier on the (updated) query units.

4.1. CLUTRR: Hop-Length Generalization
Setup.We compare pretrained Transformer baselines
(without TSRA) against the same backbone augmented with
TSRA. We report overall accuracy, short-hop accuracy (2–3
hops), and long-hop accuracy ( ≥6 hops), following the
hop-based evaluation protocol in CLUTRR (Sinha et al.,
2019).
Results.Table 1 shows that adding TSRA consistently
improves performance, with the largest gains on long-hop
instances. This supports the main motivation of TSRA:
using trace supervision to bias the model toward better multi-
step step selection, improving length generalization beyond
what is achieved by end-task supervision alone.
4.2. RuleTaker: Depth Generalization

(Clark et al., 2020). For this experiment we report the best

A. Appendix
A.1. Entity Span Alignment and Masking
We align surface forms to token spans to pool unit vectors from token states. Given a raw text and a name string, we first
attempt anexact bracket match(e.g., [Alice]) and fall back to a raw string match if needed. We use tokenizer offset
mappings to convert character spans to token spans. If a name appears multiple times, we choose the first occurrence for
stability. If alignment fails, we set the span to invalid (padded as (−1,−1) in the batch tensor), and its pooled embedding is
set to the zero vector.
Masking.Invalid units must be masked in (i) attention logits and (ii) any auxiliary supervision that indexes unit nodes. In
our implementation, padded logits are filled with a large negative constant (e.g., −104), so that Softmax assigns negligible
probability mass and cross-entropy remains well-defined.
A.2. Graph Construction and Shortest-Trace Labels in CLUTRR
For CLUTRR, training data includes a kinship graph specified by edges and relation types. We construct a directed graph by
adding: (i) the original directed edges with their relation type, and (ii) an inverse edge for each original edge. The inverse
relation label is inferred from a predefined mapping (e.g., father↔son /daughter) using the gender of the inverse
edge’s source node; if no mapping exists we fall back to aninverse prefix.
We then compute the shortest directed trace from the subject to the object unit and record: (i) the node index sequence
(v0, . . . , vT ), and (ii) the edge label sequence(r0, . . . , rT−1 ) along the trace. These labels are used only for training auxiliary
losses.
A.3. Model Details and Complexity
Per-sample computation for variable N.TSRA requires pairwise interactions and scales as O(N 2) per sample. To
avoid quadratic overhead from padding to the maximum N in a batch, we compute attention per sample on its valid prefix
and write the resulting step-selection logits into a padded tensor initialized with a large negative constant.
